## 🧠 Overview

Bandicam is a Windows recording tool designed to capture desktop activity, gameplay, and video from compatible external devices. It enables users to record a complete screen, a specific region, or an individual application window, making it useful for gaming videos, tutorials, software demonstrations, and presentations.

Its collection of capture modes combines video and audio recording with webcam overlays, configurable quality settings, and convenient recording controls. Users can tailor their setup to suit different projects and manage their saved footage from a single application.

## Additional Information for Windows Users

Bandicam includes several recording modes so users can select the capture method that fits their task. Screen Recording is suitable for desktop demonstrations, Game Recording is designed for compatible games, and Device Recording supports video input from compatible hardware.

Recording performance varies with resolution, frame rate, encoding settings, and the capabilities of your PC. High-resolution footage requires more storage, while supported hardware encoding may help reduce the load on the CPU.

For clear audio, verify the microphone and system sound sources before beginning a session. Selecting the appropriate capture mode and checking the recording area can help ensure that the finished video contains the intended content.
